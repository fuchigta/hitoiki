# 日々の使い方

常駐アプリ（`hitoiki-app.exe`）の画面と通知、トレイの使い方です。同じことはすべてコマンドラインからもできます（[CLI リファレンス](./cli.md)）。

画面は左のメニューから切り替えます。コマンドラインからは `hitoiki ui <画面>` で開けます（画面名は [CLI リファレンス](./cli.md#hitoiki-ui-の画面名)）。

## 今日

一日の流れを確認する画面です（`today`）。

- **いま**: 進行中（いまの枠があればその枠も）と、進行中（doing）のタスクの開始からの経過時間。「完了にする」で終えられます。
- **今日の合計**: 記録された時間の合計と、そのうちエージェント対話の時間。無操作と休憩は合計に含めません。
- **確認待ち**: 「要確認 N 件」と、今日の分のおよその長さ。「仕分けを開く」で仕分けへ移れます。
- **タイムライン**: 予定（カレンダー）・計画ブロック・実績を縦に並べ、現在時刻の線を引きます。種別ごと・タスクごとの内訳も出ます。
- **未回答の問いかけ**: 答えなかった通知。答えなくても構いません。
- カレンダーを登録していないときは、「カレンダーをつなぐと会議を自動判定できます」と 1 回だけ案内します（閉じると二度と出ません）。

### 1 日をデザインする

今日の画面のタイムラインの「計画」の列で、ブロック（時間の枠）を直接作れます。

- **作る**: 空いている所を上下にドラッグ（15 分刻み）、またはクリック（1 時間）して、ラベル・タスク・集中を入れて「追加」。
- **動かす・伸ばす**: ブロックをドラッグで動かし、上端・下端をドラッグして長さを変えます。クリックで編集、「×」で削除。ほかのブロックや予定と重なる場合は、フォームに知らせます（重ねても保存できます）。
- **今日のデザイン**: 1 日の初め（今日のブロックが 0 件のとき、始業の通知をクリックしたとき、振り返りの案内から、タイムラインの「今日のデザイン」ボタン）に開くモードです。テンプレートの適用、今日のカレンダー予定、ブロックにしていない未完了タスクの一覧が並びます。タスクはタイムラインへドラッグするか、選んでからタイムラインをクリックするとブロックになります。終わったら「完了」を押すと通常の表示に戻ります。

### ブロックのテンプレート（働き方のパターン）

「水曜は定例があるのでこの並び」「金曜は内省の時間を取る」といった配置を、名前を付けて保存できます。

- **保存**: 配置してから「この日の配置をテンプレートとして保存」。計画画面の「テンプレート」でも、ブロックと時刻（HH:MM）を指定して作ったり編集したりできます。
- **曜日の既定**: テンプレートに曜日（複数可）を割り当てておくと、その曜日の「今日のデザイン」で「水曜日のパターンを適用しますか？」と提案します。
- **適用**: テンプレートを選ぶと、作られるブロックと、既存のブロック・予定（busy）との重なりをプレビューします。重なる枠は「作らない」か「重ねて作る」かを選べます。「直前の適用を取り消す」でその適用で作ったブロックだけを消せます。
- テンプレートがまだ無いときは「よく使うパターンを保存しておくと、毎朝ワンタップで並べられます」と案内します。

## 仕分け

自動判定に確信が持てなかった区間（要確認）を確定する画面です（`review`）。期間（今日・昨日・今週・先週）を選んで一覧し、区間ごとに次を指定して「確定」します。

- **タスク**: 割り当てるタスク。
- **種別**: 作業・エージェント対話・会議・割り込みなど。
- **活動**: 「コードレビュー」のような活動ラベル。
- **この条件を常にこのタスクに**: チェックすると、その区間から帰属ルールを作り、以後は同じ条件が自動でそのタスクになります。
- **割り込みとしてタスク化**: 区間のタイトルから新しい割り込みタスクを作って割り当てます。

1 分（`review.min_sec`）未満の短い区間は、一覧に出さずに隠します。「短い区間 N 件を表示」のチェックで表示できます。隠した区間も削除はされず、そのまま集計に含まれます。今日の画面の「確認待ち」の件数は、隠している短い区間を含めず、短い区間の件数を別に添えます。なお、タスクバーやスタートメニューなどを一瞬だけ前面にした時間は、そもそも独立した区間にせず前後の作業に含めます（[設定](./configuration.md)の `collect.transient_exes`）。

確定した内容は最優先で適用され、再計算しても上書きされません。

## 通知

Hitoiki は、ときどき通知で「いま何してた？」などと問いかけます。ボタンを 1 回押すだけで答えられ、答えはチェックイン・ハッスル・通知の一時停止として保存されます。答えなくても構いません。

主な問いかけの場面は、始業・終業・週次の振り返り、割り込みの後、会議が延びているとき、切り替えが多いとき、長時間の集中、遅い時間までの作業です。1 日の上限（既定 6 件）と最小間隔（既定 60 分）があり、会議中や集中ブロックの計画中は保留されます。回数や時刻は [設定](./configuration.md#通知) で変えられ、`push.enabled = false` で止められます。

通知は Windows のトースト（ボタン付き）です。出せない場合は、画面右下の小さなポップアップに切り替わります。通知本体をクリックすると、該当する画面（振り返りなど）が開きます。ボタンが効かない場合は [トラブルシューティング](./troubleshooting.md#通知が出ない場合) を参照してください。

設定画面とトレイの「通知を 1 時間止める」で一時的に止められます。通知のボタンに「今日はもういい」が出る場合は、その日の終わりまで止まります。

## 振り返り

始業・終業・週次の問いを AI に作らせ、回答を書いて保存する画面です（`reflect`）。

- 種別（始業・終業・週次）と基準日を選び、「問いを生成」を押します。
- 問いに対する回答を Markdown で書いて保存します。過去の振り返りも一覧から開けます。
- 時間の使い方に良し悪しの評価はつけず、問いかけの形で寄り添います。

AI の呼び出しは、設定 `ai.command`（既定 `claude -p`）で指定したコマンドに標準入力でプロンプトを渡す方式です。Hitoiki 自身はネットワークに接続しません。コマンドが使えない環境では、[設定](./configuration.md#ai-コマンド) を見直してください。

## タスク

タスクの作成・編集・状態変更をする画面です（`tasks`）。

- 状態は「未着手」「進行中」「完了」「やめた」。進行中にできるタスクは、既定では 1 つだけです（`task.single_doing`）。
- 緊急・重要のフラグ、見積もり（任意）、本文（Markdown）、スキル、リンク（Issue など）を付けられます。実績時間の入力欄はありません。実績は記録から自動で算出されます。
- 割り込みタスクは通常のタスクと区別されます。
- **保存**: 編集は「保存」ボタン（本文の下とフォームの最下部）か Ctrl+S で保存します。自動保存はしません。保存すると「保存しました」を数秒表示し、失敗したときはボタンの近くにエラーを出します。
- **未保存の確認**: 保存していない変更があると「未保存の変更があります」と表示し、保存ボタンを強調します。そのまま別のタスクを選ぶ、別の画面へ移ると、破棄してよいかを確認します（「キャンセル」で留まります）。
- **本文のプレビュー**: 本文は「編集」と「プレビュー」を切り替えられます。タスクを開いたときは、本文があればプレビュー、空なら編集です。
- **帰属ルール**: 「アプリ名」「ウインドウタイトル」「作業ディレクトリ」「リポジトリ」「URL」「ブランチ」のパターン（glob / 正規表現 / 含む）をタスクに結び付けます。条件に当たる時間は自動でそのタスクになります。

## 計画

タイムブロッキングの画面です（`plan`）。「計画」の列を上下にドラッグして 15 分刻みでブロックを作り、タスクやラベルを結び付けます。「集中」にしたブロックの間は、通知が保留されます。カレンダーの予定と実績を並べて見られます（計画と実績）。

## 記録

その時の気持ちや出来事を残す画面です（`records`）。

- **チェックイン**: エネルギー・気分・ストレスを 1〜5 で。一言メモも書けます。
- **ハッスル**: その日の気になったこと（デイリーハッスル）と強さ。
- **ABC の記録**: 出来事（A）、受け止め方（B）、感情（C）の記録。AI に受け止め方を掘り下げる問いを作らせることもできます。

## OKR・スキル

目標（Objective）とその成果指標（KR）、スキルを管理する画面です（`okr`）。タスクを KR やスキルに結び付けると、レポートで目標別・スキル別の時間が見られます。スキルは階層にでき、同梱のプリセットを取り込めます。複数のスキルが付いた時間は、それぞれに全時間を数えます。

## レポート

期間内の時間を集計する画面です（`report`）。期間（今日・昨日・今週・先週・任意の期間）と、集計の軸（タスク・活動・象限・OKR・スキル・エージェント・種別）を選びます。

## 設定

`settings` 画面では、自動起動、通知の受け取り、新しいバージョンの確認（[更新の確認](./configuration.md#更新の確認)）、テスト通知、通知の一時停止、オンボーディングの再表示ができます。「設定ファイル」では、キーと値（TOML）を指定して任意の設定を書き換えられます。設定の内容は [設定](./configuration.md) を参照してください。

## トレイ

常駐中はタスクトレイにアイコンが出ます。メニューには次の項目があります。

- 現在のタスク（「いま: ...」）と今日の合計
- **タスクを切り替え**: 未完了のタスクから選んで開始
- **チェックイン（エネルギー）**: 1〜5 を選ぶだけで記録
- **ハッスルを記録…**
- **新しいバージョン vX.Y.Z をダウンロード…**: 新しい版が見つかっている間だけ出る（`general.update_check` が `true` のとき）。押すとリリースページをブラウザで開く
- **UI を開く**
- **通知を 1 時間止める**（止めている間は「通知の一時停止を解除」）
- **終了**: 常駐を止める。進行中の区間は閉じて保存されます

ウインドウを閉じても常駐は続きます。ログオン時に自動で起動したい場合は `general.autostart` を有効にします（既定で有効）。
